## 1. 背景与目标

* 做一款**第三方红果短剧客户端**：设备端完成请求/签名/解析/播放/下载，不依赖自建中转服务（沿用 guoapp 已验证闭环）。
* 与 guoapp 的三点差异：① **Rust 后端核心**（替代 Go 核心）；② **iOS 液态玻璃 UI**（guoapp 是常规 Material）；
  ③ **源逻辑走 `SourceProvider` trait 抽象 + 运行时注册表**，红果是其唯一实现，**不留编译期源开关**（guoapp 是 `--all-sources` 双变体，换源=换包）[G15]。
* 首版只跑通在线播放闭环：浏览—搜索—详情—选集—播放—重试；其余按优先级后置。
* **P0 唯一源 = 红果**。guoapp 用 20 个站源验证"设备端闭环"可行，但本项目不复制其多源：
  红果是其中唯一"能力完整"的源（目录/搜索/联想/推荐/榜单/详情/取流全有，EVIDENCE §17.3），
  且红果需要 **X-Gorgon 签名 + 设备伪装 + spade_a 密钥派生 + AES-CBC 解密**（EVIDENCE §17.1），
  属必须代码实现的特权源——**这既是我们选它做唯一源的理由，也是源扩展机制对 P0 零收益的理由**。
* **取流双轨（v0.6，联网调研后修订）**：
  **① 官网 SSR 免签** `hongguoduanju.com/player/{sid}/{vid}` → 明文直链，**覆盖了可试看集**；
  **② App API 签名** fqnovel `video_model` → CENC，覆盖全集。
  **M0 只做 ①**：免签、明文、不碰 CENC，即可跑通完整播放闭环；② 记 M1/M2 增强。
* **~~唯一结构性风险~~（v0.6 已化解）**：v0.5 曾把"mpv `decryption_key` 能否解红果 CENC"列为全项目唯一阻断项。
  调研后确认存在**免签明文路径**，CENC 降级为增强项，**M0 不再有"做不出来"的风险**；
  CENC 验证改到 M1，仍须做，但**不阻塞 M0 与 UI 工作**。
* **红线（v0.6 新增）**：guoapp 的第三级取流走 **`djapi.999888456.xyz`（第三方自建中转，非红果官方域名）**——
  **本项目禁用**，与 §1"不依赖自建中转服务"直接冲突，且该域名随时可能挂掉/跑路/投毒。
* **渲染基线（Q9 修订）**：基线 3.47.4 仍属 3.47 线 → **桌面（Windows/Linux/macOS）Impeller 默认成立**，全面 Impeller 目标不变；
  Android API 29+ 默认、旧机 GLES 回退；iOS 自 3.29 起仅 Impeller。**不建 Skia 双渲染路径**——回退标志仅作应急。
  **降级情形**：若 M0 spike 判定 3.47.4 不兼容而回退 3.38.10，桌面默认回到 Skia（Impeller 需手动 flag），
  macOS 仍走 Impeller（3.29 起默认），Windows/Linux 从"平台策略钳 standard"退化为"shader 能力不足"——
  验收档位结论不变（仍 standard），但 **Windows premium 的实验路径同时封死**，且 wide gamut 不再默认开。

## 2. 用户与角色

| 角色 | 说明 |
|---|---|
| 本机用户（唯一） | 浏览、搜索、播放、追剧、历史、下载；设置即全局设置，无账号/密码/PIN |
| 源开发者（第三方） | 按 SourceSpec 开发 `.wasm` 源包，自行分发 |

* **单用户全局存储（Q3 决断）**：追剧/历史/偏好/设置全部存本机全局命名空间，无用户维度。
  数据模型**不预留 `user_id`**——多用户是被 guoapp 事故逼出来的设计（PIN 12 万次迭代、快照提交、profileEpoch 在途作废、
  损坏配置回退成无密码管理员 [G6]），本版本不做，也不留半成品维度；P1 若真有需求，从数据模型层重设计而非"补字段"。
* 原"管理员"概念取消：源权限分配、网络与资源（代理/并发）、备份恢复统一为**全局设置**，无鉴权门槛
  （设备物理占有即权限；设备保密是操作系统锁屏的事，不是 App 层的事）。
* 备份含追剧/历史/偏好/设置，**不含视频/密钥/插件私配**；损坏恢复可重试且保留原文件不覆盖
  （多用户/PIN 取消后的简化形态——guoapp 的锁死契约是为"回退成无密码管理员"事故设计的 [G6]，单用户下该风险面消失，
  但"未落盘=不新鲜"与"保存失败可见"两条保留）。是否含已安装源清单与授权决定见 QUESTIONS Q14（仍开放）。

## 3. 平台优先级（Q9 修订：基线以 media_kit 兼容为准 = 3.47.4）

| 批次 | 平台 | 渲染/基线（2026-10-14 核实） | 备注 |
|---|---|---|---|
| P0 | Android 手机/平板 | **Impeller 默认（API 29+，3.27 起）**；API <29 或无 Vulkan 旧机 → OpenGL ES 回退 → `minimal` 玻璃档 | 首发验证真机 ARM64，`--split-per-abi` |
| P0 | Windows 11 | **Impeller 默认**（3.47 线）= GLES via ANGLE → D3D11，不是 Vulkan（Vulkan 桌面后端仍是 P2 设计稿）；引擎日志确认句 `Using the Impeller rendering backend (OpenGLESSDF)`；SDF 文本 + glyph gamma 校正默认开。降回 3.38.10 则桌面默认 Skia，需手动 flag 开 Impeller | 玻璃 `premium` 在 `adaptiveQuality:true` 下仍被钳 `standard`（包 Phase 1 平台规则，与 Impeller 无关）[G9]，P0 按 standard 验收；Windows 冲 premium 记 P1 实验（需真机验证 Impeller-ANGLE 下双通道 GLSL 表现；**降级 3.38.10 则该实验取消**）。**原生库仅 x64**（见下方 Windows 硬约束） |
| P0 | macOS | **Impeller → Metal 默认**；wide gamut 3.47 起默认开；最低版本升至 macOS 12（降级 3.38.10 则无 wide gamut 默认、最低 10.15） | 三档全可用，桌面 GPU 多落 premium；Intel Mac 逐步淘汰，双架构构建按需（ARM64-only 可配） |
| P1 分支 | iOS | Impeller → Metal（iOS 仅 Impeller，3.29 起无 Skia）；**最低版本升至 iOS 15**（3.38 线为 13） | **P1 末位（Q12）**：media_kit_video 上游渲染上下文失败会 `exit(1)` 不回到 Flutter 错误页，需平台级兜底（guoapp 0.2.40 禁用硬件纹理）[G14]；后台下载仅前台+回前台续传；画中画单独处理 |
| P1 分支 | Linux | Impeller 默认（GLES，3.47 线）；SDF 无条件开 | 同 Windows 按 standard 验收，需装系统 mpv 依赖 |
| P1 分支 | Android TV | 同手机但遥控焦点 | 统一横屏、48×48 焦点、大字布局单独验收 |
| P1 分支 | OHOS | **P0 发版后再调研（Q11）**：Flutter-OH canary + DevEco，`flutter build hap` | 主 SDK 出不了 OHOS 包；`media_kit` 无 ohos 适配，播放器需接原生；不阻塞 P0 |

> **基线（2026-10-14 修订）**：**Flutter 3.47.4 / Dart 3.13.3** —— 取"media_kit 1.2.6 有实证兼容"的版本（证据 EVIDENCE §16）；
> Rust 1.96.0 / Go 1.26.4（Go 仅 guoapp 参考用）。3.47.6 = 2026-10-01 同线 hotfix（Dart 3.13.5），M0 冒烟通过后小步跟进，**不追 3.50**（预计 2026-11 转正）。
> **降级目标**：Flutter **3.38.10 / Dart 3.10.8**（3.38 线最新 patch；media_kit 1.2.2 changelog 明确 "feat: flutter 3.38.x support"）。
> Android 构建基线随基线版本定：3.47 线 = AGP 9.1.0 / Gradle 9.3.1 / compileSdk 36 / minSdk 24 / Java 17；
> 3.38 线 = AGP 8.11.1 / Gradle 8.14 / compileSdk 36 / minSdk 24 / Java 17。
> Android 15+ 要求 `.so` 16KB 页对齐（3.38 起默认 NDK r28），P0 构建即接入 [G12]。

**Windows 硬约束（新增，P0 必读）**：guoapp 用 `dependency_overrides` 把 `media_kit_libs_windows_video` 指向自维护包
`1.0.11+duanju.1`（"Pinned Windows native media libraries"，按 URL + SHA256 下载 pinned 归档并校验），其 CMake 硬性要求
**Windows x64**（`if(NOT CMAKE_SIZEOF_VOID_P EQUAL 8 OR FLUTTER_TARGET_PLATFORM STREQUAL "windows-arm64") → FATAL_ERROR`），
对应上游 media_kit 1.2.4/1.2.5/1.2.6 三条 "fix(windows): long file path support"。
**M0 决断**：直接用上游现成库，还是照 guoapp 做法自建 pinned 包（可控 + 可复现 vs 维护成本）；
无论哪种，**Windows ARM64 在原生库层面即不支持**——"Win x64 首发、ARM64 后补"的后补不是单纯打包问题，需单独评估。

**3.47 升级迁移成本（进 M0 出口条件）**：

1. **Material/Cupertino 独立包**：3.47 起 `material_ui`/`cupertino_ui` 可独立于 SDK 发版（v1.0），核心 SDK 内旧设计库排期 Fall 2026 弃用。
   M0 定夺迁移策略（`dart fix --apply --code=migrate_design_widgets` 立即迁移，或迁移期内暂留旧 import），
   并验证玻璃包 MaterialApp 三件套（ARCH §4）在新 import 下行为不变。降级到 3.38.10 则本条不适用（旧 import 仍是唯一路径）。
2. **SDF 文本 + glyph gamma 校正**（3.47 线生效）：字形边缘/字重微变，大字布局回归矩阵（F-09）必须在新渲染器下重跑（ARCH §8 golden 回归）。
   降级 3.38.10 后桌面默认 Skia，本条降为"未来升级时的已知回归项"。
3. **media_kit 1.2.6 兼容性（从"最大未知"降为"M0 必验"）**：guoapp 已在 3.47.4 上用同版本组合完成编译验证（EVIDENCE §16），
   风险不再是"能不能编过"，而是"播放真机是否回归"——guoapp 自 2026-09-21 起暂停集中验证，其验证范围是编译 + `dart analyze`，
   **未覆盖播放真机回归**。M0 spike 必验：Windows/macOS 播放三件套（MP4 / AES-128 HLS / CENC）+ 硬件解码 + 长路径场景。
   不兼容则按降级目标 3.38.10 执行并留痕（PRD §9 快照制度）。

## 4. 源与内容需求（v0.5：P0 只有红果）

* **唯一源 `hongguo`（红果）**：随包内置、**默认启用、不可卸载**（P0 没有第二源，"禁用"没有意义）。
  能力：分类/目录分页/在线搜索+联想/推荐（真人/漫/AI）/榜单/详情/分集/取流 —— **完整覆盖 F-01~F-06**（EVIDENCE §17.3）。
  **弹幕能力暂缓（Q1）**：F-08 编号保留不复用；契约与全套常量冻结于 SourceSpec §3.4 / EVIDENCE §7，P1 备查，不进 P0 工作量。
* 红果的**特权实现清单**（全部在 Rust 引擎内，不进 Dart/备份/日志）：X-Gorgon 签名、Android 设备伪装参数、
  持久化的 `device_id`/`iid`、spade_a → CENC 密钥派生、备用接口 AES-CBC 响应解密、`bytevc2` 编码过滤（EVIDENCE §17）。
  **v0.6：以上只在"轨道 ② App 取流"时才需要**——元数据与可试看集走官网 SSR，**完全不触碰这些特权逻辑**。
* **编码选择（v0.6 补充）**：社区实测 **1080p = bytevc1 = HEVC（通用可播）**，720p/540p/480p/360p = **bytevc2（字节自研，ffmpeg 不解）**。
  P0 优先 1080p(bytevc1/HEVC) 或 h264/avc1，**bytevc2 一律跳过**（与 guoapp 过滤逻辑一致）。
* ~~官方扩展源 `official/*`~~、~~第三方扩展源 `third/*`~~ —— **⏸ 延后至 P2**（v0.5 决策）。
  其原有条款（签名下发、默认关闭、WASM 沙箱、`domains` 白名单、启停卸载、不进备份）**保留在 SourceSpec §1–§7 备查，不进 P0/P1**。
  P2 重启时，扩展源实现与红果**同一个 `SourceProvider` trait**（SourceSpec §11.1），引擎调度与 UI 零改动。
* **VIP 三态（仅预留字段，Q4=a）**：模型保留 未知/免费/VIP 三态与"未知不覆盖已知"语义（guoapp 黄豆场景验证 [G8]），
  但**首版 UI 不展示、不过滤、不划线**——官方源首批是否含 VIP 源未定，字段留着不占首版工作量。
* **红果特权逻辑边界**：签名密钥、设备伪装参数、spade_a 派生、AES-CBC 解密**全部封闭在 Rust 引擎内**，
  不进 Dart、不进备份、不进日志；诊断输出须脱敏（沿用 guoapp `diagnostics.go` 全局替换策略 [G10]）。
  **P2 若开放扩展源**，这类特权仍须经 host 凭证 API 暴露，**插件不得自行抓取官网 JS**，否则审计面失控 [G2, G15]。
* **TLS 指纹（Q8=a）**：P0 不做 Chrome 指纹。**红果走 X-Gorgon 签名，不依赖 TLS 指纹**（guoapp 的指纹白名单只有黄果视频/皮果两类，不含红果），
  rquest 评估记 P1 引擎演进项，对 P0 无阻塞。

## 6. 非功能需求

* 性能：目录缓存 15min（先展缓存再更新，**未落盘结果不标新鲜**）；海报 30 天/256MB/2000 张/单张 20MB；预加载≤6s/4MB/8 请求；长列表用 `minimal` 玻璃。
* 网络与资源（全局设置可配）：目录并发 1–6、间隔 0–5000ms，**默认 3 / 250ms**；下载并发默认 2、可设 1–6；按 source 粒度串行 gate、前台优先；403/429/CF 挑战触发退避 1min 起、尊重 Retry-After、**封顶 30min**；**媒体请求（分片/密钥/播放列表）不走限流器**；代理自动/直连/手动（http/https/socks5/socks5h，禁 query/fragment），**127.0.0.1 本地流服务永远直连**，PAC 不执行（仅配置指引），代理地址不进备份；TLS 校验不关闭 [G2]。
* 安全：第三方 WASM 无 WASI 文件/网络默认权；代理地址不进备份；cookies/访客 token 不进备份/同步，只活引擎内存；凭证仅按 origin 注入、过期即拒；**播放密钥（hlsKey/cencKey）不进备份/同步/日志**（Q5=a 的硬约束）[G2, G6]。
* 兼容：Android ARM64 真机；**Win x64 首发**（media_kit 原生库仅 x64，Windows ARM64 需单独评估，见 §3）；macOS 双架构（ARM64-only 可配）；`.so` 16KB 页对齐；签名包体积极小化（tree-shake + 分 ABI）。
* 备份：上限 8MiB；损坏恢复可重试、保留原文件不覆盖（§2 简化形态）；记录上限 favorites 20000 / history 300 / recentSearches 20；是否含已安装源清单与授权决定待 Q14。
* 可测性：所有 Repository/ViewModel 可单测；源包有合规测试向量（见 SourceSpec）；关键写路径有故障注入（false/throw/after 三种）回归 [G12]。

## 9. 验收边界纪律（沿用 guoapp 制度）

* 未真实验证的功能明确标注"开发快照"，不作为通过验收的版本；README/文档首行标注当前快照状态。
* 历史检查记录不得作为后续新增功能的验收结论。
* 恢复集中验证时：先完整实现当前交付范围，再集中执行静态检查、构建、自动化、设备验证；不每改一个小功能就测试。
* 用户反馈驱动的修复必须在文档留痕（版本号+证据+验证范围），便于复盘。
* **渲染器/框架版本变更视同功能变更**：基线升级（3.47.4→3.47.6 或降级 3.38.10）、Impeller 迁移、独立 UI 包迁移均需按上述制度留痕（快照状态+验证范围），不得静默跟发。
* **基线决策规则（Q9 修订固化）**：Flutter 版本由 media_kit 兼容性反向决定，不由"追最新"决定；每次变动必须以 EVIDENCE §16 的实证链 + M0 冒烟结果为依据。
