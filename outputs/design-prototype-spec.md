## 一、配色（OpenAI 灰阶 + 一支标志绿）

从「纯中性黑白」升级为 **ChatGPT 双色**：灰阶全套对齐 ChatGPT 的产品色号，
并引入标志绿 `#10A37F` 作为唯一彩色。绿色的分工沿用 ChatGPT 的实际用法——
**只表达状态与进程**；主操作仍是墨色胶囊，重型填充（主按钮 / 选中格）继续用
墨与白，界面色彩依然不与剧照抢注意力：

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 纸白 canvas | `#FFFFFF` | `#212121`（播放器用 `#000000`） | 页面底色 |
| 墨黑 ink | `#0F0F0F` | `#ECECEC` | 正文 / 标题 / **重型填充**（配 onInk） |
| 石墨 graphite | `#6E6E80` | `#B4B4B4` | 次级文字 / 未选中图标（两端过 4.5:1） |
| 银灰 silver | `#8F8F8F` | `#8E8E8E` | 三级文字 / 元信息（浅色端只作装饰） |
| 标志绿 accent | `#10A37F` | `#10A37F` | **状态与进程**：进度 / 加载 / 开关 / 焦点 / 描边 / 图标 |
| 深绿 accentDeep | `#0B7A61` | `#19C37D` | 绿色小字：链接 / 徽章 / 选中胶囊文字 |
| 绿浅底 accentSubtle | 绿 12% | 绿 20% | 选中行 / 悬停 / 弱提示底 |
| 发丝线 hairline | `#E5E5E5` | `#3D3D3D` | 分隔线 / 描边 |
| 浅雾 mist | `#F7F7F8` | `#171717` | 输入底 / 凹陷面 / 进度轨道底 |
| 玻璃（浅） | 白 62% + 背景模糊 26 + 白描边 75% | — | 功能层材质：Tab 栏 / 顶栏圆钮 / 搜索框 / 侧栏 |
| 玻璃（深） | — | 黑 35% + 背景模糊 24 + 白描边 28% | 覆盖在画面上方的控件（播放器） |

四条使用纪律：

1. **墨色是主操作填充**——主按钮一律「墨色胶囊 + 反白字」，与 ChatGPT 现行的黑色主按钮同构；
2. **绿色只表达状态与进程**——进度、加载、开关、焦点、选中标记、徽章、链接；不做装饰、不刷大面积；
3. **绿色小字一律用 accentDeep**——浅色底上标志绿只到 3.20:1（图形级）；白字也不进绿底做小号；
4. **玻璃只出现在功能层**——Tab 栏、顶栏控件、搜索、侧栏、播放器控件；内容层（海报 / 画面）保持不透明。

### Tab 栏选中态（本轮修正）

弃用「纯黑胶囊」。选中态改为 **iOS 26 式浮起玻璃镜片**：白色 92% 底 + 1px 墨色 8% 描边 +
柔和投影（0,2,10,10%），图标与文字转为墨黑并加粗。未选中保持石墨色。
深色场景沿用同一逻辑（白色镜片 + 深色内容）。

## 二、字体

- 界面文字：Noto Sans SC（原型）；实现沿用系统字体（PingFang / SF），字阶维持现有六级；
- 数字与元信息：等宽字族（JetBrains Mono → 实现 SF Mono 或同类）承载集号、热度、时间码、
  倍速、榜单序号、`EP 60`、`1080P`。

## 三、几何与规格

- 控件一律胶囊；内容卡 14–22 连续圆角；缩略图 10；弹层 28；
- 触控目标 ≥ 44pt；
- 进度一律「发丝线」：3px 轨道 + 绿色填充（画面之上的角标进度用白）。

## 四、分屏要点

1. **首页**：固定液态玻璃顶栏（左：标题；右：选择源、搜索两枚玻璃圆钮；毛玻璃模糊、内容从下方滚过）
   + Kazumi 式卡片信息流（封面 2:3 + 标题两行 + 元信息一行，3–6 列随宽度自适应、触底续拉）。
2. **搜索**（v5 重做，版式对齐 Kazumi `search_page.dart`）：固定玻璃顶栏（返回 + 标题 + 常驻玻璃搜索框）；
   引导态 = 最近搜索（管理/清空两态，历史图标 + 词 + 右上箭头行）+ 热门趋势（榜单前 6，缓存零网络）；
   输入未提交 = 联想行（首行「搜索「词」」直接提交）；结果态 = 「搜索结果」头（计数 + 范围菜单）
   + Kazumi 网格（列数 = max(2, ⌊宽/180⌋)、封面 0.7、标题两行、元信息行）+ 底部「已显示全部 N 部」。
3. **榜单**：大号等宽序号（前三墨黑 / 其余银灰）+ 发丝分隔 + 玻璃排序钮。
4. **追剧**：浅雾分段控件（白色滑块）+ 每行**绿色**发丝进度线 + 更新徽章 + 「继续看」黑胶囊。
5. **详情**（v5 重做，版式对齐参考截图）：整页背景 = **海报高斯模糊**（放大 1.18 + blur 36 + 52% 背景罩层，
   34%→58% 渐隐回纯色）。窄屏（<900pt）：小海报（Hero 落点，112×168）+ 标题/题材胶囊/「已完结 · 全 N 集」；
   追剧描边胶囊（右对齐）+ [下载方钮 | 开始观看黑胶囊]；选集 = 分组胶囊 + 水平集条（集号 + 集名）；
   可展开简介（超 4 行才出「显示更多」）；底部题材标签。宽屏（≥900pt）：左列 268pt（海报 + 主操作 + 统计行
   [总集数/状态/看到]），右列 = 大标题 + 题材 + 元信息 + 简介 + 选集（下载管理链接 + 分组翻页
   `< 1-50 / 82 >` + 5 列网格）+ 题材。
5. **播放器 · 竖屏（抖音式）**：整屏沉浸；顶部返回胶囊 + 居中剧集名 + 更多圆钮；
   **右侧竖排互动栏**（点赞 / 评论 / 收藏 / 分享，含计数）；**左下文案区**（剧名 / 更新信息 /
   选集·倍速·清晰度玻璃小胶囊 / 「上滑看下一集」提示）；底部全宽发丝进度线；中央半个透明度的暂停幽灵图标。
6. **播放器 · 横屏**：为 16:9 内容准备；整屏画面 + 顶部玻璃控件（返回 / 集名 / 1080P / 更多）+
   底部控制条（播放键 / 时间 / 发丝进度 / 倍速 / 选集）。
7. **我的**：大标题 + 玻璃设置钮；账号卡（玻璃材质）+ 三项等宽统计（追剧 / 历史 / 下载）+
   设置列表（下载管理 / 观看历史 / 设置 / 关于 / 免责声明）+ 版本尾注。
8. **屏幕比例与页面关系**：播放器依据视频比例路由——9:16 内容进「竖屏版」，16:9 内容进「横屏版」；
   底部导航四页（首页 / 榜单 / 追剧 / 我的）共用玻璃 Tab 栏。
9. **平板 / 桌面（宽屏）**：左侧浮动**玻璃侧栏**（品牌行 + 四导航 + 底部设置）；
   内容区为大标题 + 玻璃搜索胶囊 + 全宽 Hero + 5 列海报货架。

## 五、页面顶部液态玻璃（本轮补充）

- 首页：**固定液态玻璃顶栏**（标题 + 选择源 / 搜索两枚玻璃圆钮，见「分屏要点」）；
  榜单 / 追剧 / 我的：标题行右侧添加**玻璃圆钮**（排序 / 管理 / 设置）；
- 搜索页（v5）：**固定玻璃顶栏 = 标题行 + 常驻玻璃搜索框槽**（`GlassTopBar.bottom`；
  40pt 高 + 8pt 底距 = 48pt 槽，`SliverGlassTopBarInset(bottomHeight: 48)` 预留净空）。
  搜索框用包内 `GlassSearchBar`（自带玻璃质感、清除钮），与栏体同在一次毛玻璃罩里；
- 详情页（v5）：固定玻璃顶栏（返回圆钮 + 分享 / 更多两枚圆钮，无标题——海报头在内容区），
  玻璃罩住下方滚过的模糊背景；
- 详情 / 播放器顶部沿用深色玻璃圆钮与胶囊（返回 / 追剧 / 更多 / 清晰度）；
- 宽屏顶栏：玻璃搜索胶囊 + 玻璃排序圆钮。

## 五·五、封面 Hero 转场（v5 新增，对齐 Kazumi）

列表卡片 → 详情页海报的**共享元素转场**，全链路一致：

- 标签 = `cover:{source}:{id}`（跨源同 id 是不同剧，标签必须带源）；
- 组件 `CoverHero`（`ui/core/widgets/drama_cover.dart`）：`transitionOnUserGestures: true`
  （iOS 边缘返回也走转场）+ 自定义 shuttle（push 取出发端渲染树、pop 取落点端，
  包 `Material(transparency)` + `InheritedTheme.captureAll`——Kazumi 同款）；
- 接入面：首页信息流卡片、搜索结果卡、榜单行、追剧行（空 id 不包——同页多行会撞标签）；
- **落点前置**：路由 `extra` 携带卡片侧 `Drama`，详情页在数据到达前先渲染海报头
  （`DetailView.initial`），否则转场开始时详情页还没有海报、飞不过去；
  深链进入（无 extra）走普通加载态，不伪造数据；
- 纪律：同一剧目不得在同一路由里渲染两份带 Hero 的封面（飞行扫描会断言失败）。

## 六、实现映射（`lib/ui/core/tokens/app_tokens.dart`）

配色 v3（ChatGPT 双色）已落地的映射：

- 灰阶：`background` 深色 `#0A0A0B → #212121`；`contentSurface` 深色 `→ #2F2F2F`；
  `surfaceElevated` 深色 `→ #3A3A3A`；`sunken → 浅 #F7F7F8 / 深 #171717`；
  `divider → #E5E5E5 / #3D3D3D`。
- 文字：`textPrimary → #0F0F0F / #ECECEC`；`textSecondary → #6E6E80 / #B4B4B4`
  （浅雾底也过 4.5:1，旧「浅雾禁次级正文」的约束随灰阶更新解除）；
  `textTertiary → #8F8F8F / #8E8E8E`。
- 绿色：`accent` 从「墨色本身」改为标志绿 `#10A37F`；新增 `accentDeep`（小字绿）、
  `onAccent`（绿底前景，只配大号字/图形）、`onInk`（墨色填充前景）；
  `accentSubtle` 改为绿色浅底；`highlight / hover / focus` 随之为绿色浅底。
- 组件：`InkPill` / `GlassActionButton(filled)` / 选集格选中 = `textPrimary` + `onInk`；
  `OutlinePill` 选中 = 绿浅底 + 绿描边 + `accentDeep` 文字；进度线（含播放器）默认绿；
  开关 `activeColor` = 绿；行内动作文字与「还有未看的」标签 = `accentDeep`。
- `test/token_contrast_test.dart` 是本文表格的回归测试：注释里的实算表就是断言。
- 实施顺序沿用既有评审批次（先缺陷 → 玻璃染色 / Hero 转场 → 播放器沉浸式 → 版式结构），
  本轮只改视觉令牌与配色语义，不改动分层与降级策略。
